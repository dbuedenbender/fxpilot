# Code of conduct

FxPilot is a technical project and should be a welcoming place for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and discuss the technical problem, not the person.
- Give actionable feedback and accept feedback gracefully.
- Respect privacy. Do not publish another person's credentials, logs or application data.

## Unacceptable behavior

- Harassment, insults, discrimination or threats
- Publishing private information without permission
- Deliberately disruptive or unsafe contributions
- Using the project to attack systems or bypass authorization

## Enforcement

Maintainers may edit, remove or reject contributions and may block accounts that violate these rules. Report concerns privately through the security advisory channel described in [`SECURITY.md`](SECURITY.md).
